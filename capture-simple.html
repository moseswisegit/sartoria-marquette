📸 Capture Screenshot - Écran d'Inscription

1 Ouvrez la page d'inscription

Cliquez sur le bouton ci-dessous pour ouvrir la page dans un nouvel onglet.

2 Ouvrez Chrome DevTools

Sur la page d'inscription, appuyez sur :

Mac : Cmd + Option + I
Windows/Linux : F12
3 Capturez le screenshot

Dans DevTools, appuyez sur :

Mac : Cmd + Shift + P
Windows/Linux : Ctrl + Shift + P

Puis tapez : Capture full size screenshot

L'image sera téléchargée automatiquement.

4 Enregistrez le fichier

Renommez l'image téléchargée en screen.png et remplacez le fichier dans :

stitch_onboarding_ia_mesures 3/écran_d'inscription/screen.png
✅ C'est tout ! Le screenshot sera mis à jour avec les nouveaux champs (bouton Revendeur, champs conditionnels, etc.)
