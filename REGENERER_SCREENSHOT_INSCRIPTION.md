# 📸 Régénérer le Screenshot de l'Écran d'Inscription

## 🎯 Objectif
Régénérer le fichier `screen.png` pour l'écran d'inscription qui a été modifié avec :
- ✅ Ajout du bouton "Revendeur"
- ✅ Champs conditionnels selon le rôle
- ✅ Nouveaux champs pour Tailleur et Revendeur

## 🚀 Méthode Simple (Sans Node.js)

### Option 1 : Utiliser l'outil HTML
Ouvrez le fichier **`capture-simple.html`** dans votre navigateur et suivez les instructions étape par étape.

### Option 2 : Étapes manuelles

1. **Ouvrir la page** :
   - Ouvrez `stitch_onboarding_ia_mesures 3/écran_d'inscription/code.html` dans Chrome

2. **Ouvrir DevTools** :
   - Appuyez sur `F12` (Windows/Linux) ou `Cmd+Option+I` (Mac)

3. **Prendre le screenshot** :
   - Appuyez sur `Cmd+Shift+P` (Mac) ou `Ctrl+Shift+P` (Windows)
   - Tapez "Capture full size screenshot"
   - Sélectionnez l'option

4. **Enregistrer** :
   - L'image sera téléchargée automatiquement
   - Renommez-la en `screen.png`
   - Remplacez le fichier dans `stitch_onboarding_ia_mesures 3/écran_d'inscription/`

## ✅ Vérification

Après la capture, vérifiez que :
- ✅ Le bouton "Revendeur" est visible
- ✅ Les champs conditionnels sont visibles
- ✅ L'image est de bonne qualité (haute résolution)
- ✅ Le fichier `screen.png` a été remplacé

## 💡 Astuce

Pour une meilleure qualité :
- Utilisez Chrome (meilleure qualité de capture)
- Assurez-vous que le zoom est à 100%
- Vérifiez que tous les champs sont visibles avant de capturer
