## 🚀 Méthode Rapide

### Option 1 : Utiliser l'outil HTML
Ouvrez **`generer-screenshots-manquants.html`** dans votre navigateur et suivez les instructions.

### Option 2 : Méthode manuelle avec Chrome DevTools

Pour chaque écran :

1. **Ouvrir la page HTML** dans Chrome
2. **Ouvrir DevTools** : `F12` (Windows/Linux) ou `Cmd+Option+I` (Mac)
3. **Prendre le screenshot** :
   - Appuyez sur `Cmd+Shift+P` (Mac) ou `Ctrl+Shift+P` (Windows)
   - Tapez "Capture full size screenshot"
   - Sélectionnez l'option
4. **Enregistrer** :
   - L'image sera téléchargée automatiquement
   - Renommez-la en `screen.png`
   - Remplacez le fichier dans le dossier correspondant
